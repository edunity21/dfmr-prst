# 디지털미래음악연구회 우수사례 웹페이지

별도 설치나 빌드 없이 실행하는 GitHub Pages용 정적 웹사이트입니다.

## 미리 보기
`index.html`을 브라우저에서 여세요. 이미지와 스타일을 유지하려면 폴더 전체를 보관하세요.

## GitHub Pages 게시
1. GitHub에서 새 저장소를 만들거나 게시할 저장소를 여세요.
2. `dfmr-web` 폴더 **안의 내용**을 저장소 최상위에 올리세요. `index.html`, `style.css`, `script.js`, `assets` 폴더가 같은 위치에 있어야 합니다.
3. 저장소 Settings → Pages에서 Build and deployment의 Source를 **Deploy from a branch**로 선택하세요.
4. Branch를 `main`, 폴더를 `/(root)`로 선택하고 저장하세요.
5. 배포가 끝나면 Pages 설정에 나타난 주소로 접속하세요.

기존 홈페이지가 있는 저장소에 올리면 같은 이름의 파일을 덮어쓸 수 있으므로 별도 저장소 또는 하위 폴더를 사용하세요. 모든 내부 경로는 상대 경로여서 하위 경로에서도 작동합니다.

## 구성
- `index.html`: 본문, 이미지 설명, 자료 링크
- `style.css`: 데스크톱·모바일·인쇄 스타일
- `script.js`: 모바일 메뉴와 현재 섹션 표시
- `assets/`: 원문 수록 사진 및 파비콘
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 제공

## 내용과 출처
제공된 「디지털미래음악연구회_우수사례(발표용).hwpx」를 바탕으로 웹 열람에 맞게 재구성했습니다. 사진은 해당 원문에서 추출했습니다. 외부 자료 링크는 원문 QR 코드를 해독해 연결했으며, 외부 사이트의 현재 가용성·접근 권한은 검증하지 않았습니다.

일정 상태는 원문의 2026년 10월 기준이며 자동 갱신되지 않습니다. 성과 수치는 대표 교사 학교의 결과입니다. 단일 문항과 영역별 지표를 구분했습니다. 원문 HWPX 자체는 공개용 파일에 포함하지 않았습니다.

## 시나브로 톤 적용
기존 시나브로 웹매거진의 종이색 배경, 버건디 강조색, 명조체 제목, 흑백 표지 사진, 둥근 모서리를 적용했습니다. Hahmlet·IBM Plex Sans KR은 Google Fonts에서 불러오며 연결할 수 없으면 바탕·맑은 고딕 등 시스템 글꼴로 표시됩니다. 이번 수정 시 index.html, style.css, assets/favicon.svg가 변경되었습니다.

## 썸네일·QR 및 영상 재생
공유 자료 7개를 썸네일 카드로 표시하며 원문 QR을 함께 제공합니다. 유튜브 영상 3개는 게시된 HTTP(S) 페이지에서 대화상자 플레이어로 열립니다. 브라우저 자동재생 정책이나 영상 소유자의 퍼가기 제한에 따라 추가 재생 클릭이 필요할 수 있으며 YouTube 직접 보기 링크를 제공합니다. 로컬 file:// 미리보기에서는 YouTube로 직접 연결합니다. 영상 썸네일 로딩 실패 시 해당 영상의 QR과 재생 버튼을 유지합니다. 플랫폼 카드는 각 플랫폼의 QR을 표시합니다.

본문 기본 글자 크기는 18px로 확대했습니다. 이번 변경은 폴더 전체를 업로드하여 적용하세요.

## 원문 전체 이미지 및 본문 배치
원문 BinData 이미지 37개(사진·수업자료·그래프 29개, QR 8개)를 모두 원본 그대로 assets/original에 포함했습니다. 각 자료는 설계·수업모형·감상·창작·평가·뮤지컬·공개수업 등 해당 내용에 배치했습니다. 사진·문서·그래프 29개는 클릭하여 확대할 수 있습니다. 마지막 공유 자료 영역은 해당 본문으로 이동하는 목차입니다.

## 색감과 확대 화면 업데이트
장밋빛·살구빛·청록·보라 계열의 섹션 색상을 적용했습니다. 공개수업 참관 자료는 첨부된 펼침면 중 오른쪽 자료만 확대하며, 뮤지컬 제작 화면과 분리했습니다. 플랫폼 화면은 클릭 시 확대하고 이름이 표시된 접속 버튼과 QR은 같은 플랫폼으로 연결됩니다.

## Melody Tree 소개영상과 로고
첫 화면 마스트헤드 바로 아래에 연구회 소개영상 「Melody Tree(DFMR 소개영상)」(https://youtu.be/NEWoCkT8YL4)과 접속 QR, 멜로디트리 로고를 배치했습니다. 게시된 페이지에서는 영상이 그 자리에서 재생되고, 로컬 file:// 미리보기에서는 YouTube로 연결됩니다. YouTube 썸네일을 불러올 수 없으면 로고 화면이 대신 표시됩니다. 머리말·꼬리말 브랜드 표시에도 로고를 넣었고, 공유 자료 목차에 소개영상 바로가기를 추가했습니다. 이번 수정 시 index.html, style.css, script.js, README.md, assets/logo-melodytree.webp, assets/qr-melodytree.png가 변경·추가되었습니다.
